# Released data

This directory intentionally contains only the released manifests, assembled baseline responses, figure assets, and this README. Restricted model weights and dense response matrices are not distributed.

`baseline_manifest.csv` is the exact 800-readout (200 per area) cohort used by the released controls. `baseline_responses.csv` is the joined control table used by the manuscript; `src/baselines/assemble.py` validates its schema and completeness.
